游戏活动计算器 v17｜支持 Python 3.9.4

本版针对 v16 误把 Python 最低要求设为 3.10 的问题。

快速使用：
1. ZIP 全部解压到普通文件夹（不要在 ZIP 内运行）。
2. 双击“启动本地计算.bat”。
3. 程序优先调用 Python 3.9，并自动创建独立的 .python_env 环境。
4. 首次运行会联网安装 NumPy、SciPy；Python 3.9～3.12 使用 numpy==1.26.4、scipy==1.13.1。
5. 浏览器自动打开 http://127.0.0.1:18771/index.html；上传 Excel 并点击本地求解。
6. 使用期间保持黑色命令窗口打开。

支持 Windows 64 位 Python。首次安装依赖时需要访问 Python 包下载源。
网页上传 Excel 不发送到外部计算服务器，本地求解器只监听 127.0.0.1。
如果失败，不会闪退，可查看同目录 startup.log。

已确认两份 Python 源码语法兼容 Python 3.9，SciPy 1.13.1 官方支持 Python 3.9；
Windows 实机双击与 Python 3.9.4 环境中的整套流程尚需在用户电脑验证。

注意：默认把 Excel 的签到空白当作 0，不自动补签到。
